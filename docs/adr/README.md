# Architecture decisions

ADRs preserve durable decisions whose rationale would otherwise be easy to lose.

Current decisions:

- [ADR 0001 — Training-free semantic scoring](0001-training-free-semantic-scoring.md)
- [ADR 0002 — Constrain before score](0002-constrain-before-score.md)

Create a new ADR only when a decision materially constrains future architecture. Do not use ADRs as implementation diaries or for temporary experiments.

Accepted ADRs are historical evidence: supersede them explicitly rather than silently rewriting the original rationale.
